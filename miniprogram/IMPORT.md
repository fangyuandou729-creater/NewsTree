# NewsTree 小程序导入说明

在微信开发者工具里导入 `D:\study\code\codex\news_tree\miniprogram`。

## AppID

`project.config.json` 里的 `appid` 已留空。导入时需要填你自己的微信小程序 AppID。

如果只是临时预览界面，可以在微信开发者工具里选择测试号或无 AppID 模式；但微信登录、用户身份、保存到相册等能力通常需要真实 AppID 和对应权限。

## 云服务

当前页面选择“不使用云服务”也可以导入和运行本地演示版。

如果后续要拿真实 `openid`，需要：

1. 开通微信云开发。
2. 在项目设置里启用云开发环境。
3. 部署 `cloudfunctions/login` 云函数。
4. 在登录逻辑里调用该云函数，把 `wx.login` 得到的 code 换成服务端身份。

## 本地可用功能

- 兴趣树首页
- 一键整理模拟新闻
- 标签添加、删除、启用
- 新闻来源添加、删除、启用
- 阅读和收藏
- canvas 绘制兴趣树
